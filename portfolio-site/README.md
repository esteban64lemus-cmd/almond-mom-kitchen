# Esteban Lemus — Portfolios

Static, no-build-step portfolio site with two tracks:

- `web-design.html` — web design & development portfolio (real case study: Almond Mom; Zaya teased as "coming soon")
- `business-assistant.html` — business/administrative & AI-augmented personal-assistant portfolio
- `index.html` — hub linking both

## Deploy

No build step — plain HTML/CSS. Fastest path:

- **Vercel**: `vercel deploy` from this folder, or drag-and-drop the folder into vercel.com/new
- **GitHub Pages**: Settings → Pages → deploy from this branch, root folder
- **Netlify**: drag-and-drop the folder into app.netlify.com/drop
